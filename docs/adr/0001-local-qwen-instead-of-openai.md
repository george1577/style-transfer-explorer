# Local Qwen2.5 instead of OpenAI for the text techniques

The reference notebooks run zero-shot, few-shot and fine-tuning against OpenAI's `gpt-3.5-turbo`, which needs an API key, costs money per call and a paid fine-tuning job, and hides the exact prompt the model receives and what it costs in tokens. The app instead runs a small open model, Qwen2.5-Instruct (0.5B by default, 1.5B optional), locally on the laptop CPU through `transformers`, behind a small text model interface (render prompt, count tokens, generate). That makes every click free and lets the app show the fully rendered prompt, chat template included, and its exact token count, which is the chapter's central cost lesson; it also makes fine-tuning a local adapter possible on an 8 GB laptop. We accept noticeably weaker writing than `gpt-3.5-turbo` (zero-shot emails ramble and miss the dataset's format more often), because the point of the app is to see and compare what each technique changes, and the style checklist makes those differences visible even when the outputs are imperfect.
